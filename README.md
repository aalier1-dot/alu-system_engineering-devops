# ALU System Engineering & DevOps

This repository contains shell scripts and configuration exercises for the
ALU System Engineering & DevOps curriculum.

## Web server

The `web_server` directory contains scripts to transfer files with `scp`,
install and configure Nginx, redirect requests, and serve a custom 404 page.
The `2-setup_a_domain_name` answer file must contain the registered root
domain name for the project.

## SSH

The `ssh` directory contains exercises for SSH keys and client configuration.
